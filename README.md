# Machine Learning Algorithms: Custom Models vs. Scikit-Learn and PyTorch models

**Project Overview**
This repository is dedicated to understanding fundamental machine learning algorithms by building them from scratch. The project includes custom implementations of Principal Component Analysis (PCA), Linear Regression, Logistic Regression, and an Artificial Neural Network (ANN). These custom algorithms were then benchmarked against industry standard libraries like `scikit-learn` to compare their overall accuracy, performance, and training speed.

As a continuation of this project, the same models were rebuilt in PyTorch using modern deep learning tools (custom `nn.Module` classes, the Adam optimizer, and mini-batch `DataLoader` training) and evaluated on a held out test set.

### Technical Stack
* **Languages:** Python
* **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn, PyTorch
* **Environment:** Jupyter Notebook
* **Techniques Used:** Forward/Backward Propagation, Gradient Descent, Adam Optimization, Eigen Decomposition, Singular Value Decomposition (SVD), Stratified Train/Test Splitting
  
---

### The Dataset
The dataset used for this project (`sample_data_for_project_final.csv`) consist of **864 samples** and **15,606 variables**. 

There is also a metadata file (`sample_metadata_for_project_final.csv`) that assigns a binary label (either `0` or `1`) to each sample. Before doing any predictive modeling, I mean centered the data so it was ready for analysis.

***Part 2: PyTorch Implementation (`PyTorch_models.ipynb`)***

### Pipeline Workflow

Data Import -> Stratified 80/20 Train/Test Split -> Standardization (fit on training data only) -> Model Setup (`nn.Module`) -> Mini-Batch Training (Adam) -> Evaluation on Held Out Test Set

To prevent data leakage, the mean and standard deviation used for standardization were computed on the training set only and then applied to the test set.

---

### Results

<img width="520" height="157" alt="pytorch_results" src="https://github.com/user-attachments/assets/b76bbe3a-273b-4136-93fc-e9ab954f4484" />

The ANN (99.42%) and Logistic Regression models(98.84%) using pytorch received high accuracy meaning they successfully
learned the biological patterns.

Linear Regression: Test R² of -17,835. With far more features (15,606) than training samples (~690), linear regression overfits the training labels, and its unbounded continuous predictions fail badly on unseen samples. This shows why classification requires a bounded output such as a sigmoid activation.

PCA (via SVD): The top two principal components explain 11.76% of the total variance (PC1: 6.75%, PC2: 5.01%), indicating the biological signal is distributed across many variables rather than driven by one or two.


**Key Takeaways:**
The PyTorch ANN and logistic regression models generalized well to unseen samples, with less than a 1.2 point gap between training and test accuracy. Using Adam reproduced the smoother convergence seen in the SKLearn models in Part 1.

### Future Improvements
While the custom models demonstrated strong baseline performance, future iterations of this project could include:
* **Algorithm Optimization:** Implementing the Adam optimizer or adaptive learning rates within the custom ANN scripts to achieve smoother training curves comparable to SKLearn.
* **Robust Validation:** Integrating k-fold cross-validation to further ensure the models generalize well and do not overfit the training data.
* **Bioinformatics Applications:** Applying these foundational algorithms to real-world genomic or clinical datasets, such as drug response screening or gene expression classification, to bridge core machine learning concepts with biotechnology.
